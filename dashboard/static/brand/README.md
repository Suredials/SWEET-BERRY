# SweetBerry / EraConTUTO visual identity

The raspberry-terminal mark and `team-banner.png` were supplied by the project
owner. The transparent mark was extracted from that supplied reference; the
original reference files in Downloads are preserved. The PNG favicon reuses the
same transparent mark.

The dashboard uses a dark navy background, raspberry accents, violet structure
and lime status indicators. Pixel typography is restricted to the product name
only; page headings, evidence, reports and tables retain reading fonts.

Silkscreen is by The Silkscreen Project Authors, distributed under the SIL Open
Font License 1.1. See [SILKSCREEN-OFL.txt](SILKSCREEN-OFL.txt) and the
[upstream font repository](https://github.com/googlefonts/silkscreen).
The font is served locally; the dashboard needs no external font request.

Reduced-motion preferences are respected. The theme is implemented in
`../brand.css` on top of the existing layout and does not change telemetry,
detection, scoring or collection behavior.
